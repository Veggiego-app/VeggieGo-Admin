# VeggieGo Admin Panel

Admin Web Panel for VeggieGo Pure Veg Food Delivery.

## Features

- Dashboard
- Restaurant Management
- Rider Management
- Customer Management
- Order Management
- Analytics
- COD Settlement
- Delivery Charge Settings
- Commission Settings
- Live Order Monitoring
- Reports
- Firebase Integration

## Technology

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Functions
- Firebase Hosting
